# ARDC\_Analysis

Scripts for analyzing raw data collected in the Audiology Research Diagnostics Core.



\## Main folders

\### Analysis and preprocessing

This folder contains the major scripts needed to compile raw data from each individual measure into a single visit structure. There is also code for recompiling the old visit structures into the newer standardized format. 



\### SNAPlab Online

This folder contains the code needed to analyze data that comes from Snap Lab online measures. There is currently code to analyze the gap detection task, the headphone check, MRT in babble, and STM.



\### Data Organization

This folder will contain the scripts necessary to compile all ardc/ardr data into a single CSV which can be used for further analysis
